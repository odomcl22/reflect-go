From drive to workstation
  1. Start your engine
    Keep Automatic compute selected, choose an eligible model, and click Start engine. Reflect Go probes acceleration on this computer and falls back to CPU when needed.
  2. Open your client
    Paste a project folder outside the Reflect Go collection. Open the portable Codex, Claude Code or OpenCode CLI. Each opens in its own terminal; use one client at a time.
  3. Approve the local connection
    Claude may ask whether to use the supplied API key, with No recommended. For a session launched here, choose Yes to connect to Reflect Go. Normal project and tool permissions still apply.
  4. Finish and unplug
    Finish your client task, stop the engine, then use Quit workstation below. Closing this browser tab alone leaves the engine running. To reopen this page, double-click START Reflect Go.exe on Windows. Use Quit workstation before ejecting.
One library. Different computers.
The drive carries weights and runtime software. Your computer supplies CPU, GPU, RAM, drivers, and permission to execute programs. Keep the complete Phase 4.5 folder beside Models when moving the collection.
Linux needs a compatible glibc system and executable storage. Chromebooks need an enabled Linux environment, compatible hardware and permitted access to the drive. A no-exec mount is reported; Reflect Go does not silently copy itself onto your computer.
Automatic selection can use Metal on Mac, Vulkan on compatible Windows/Linux machines, or CPU. If the model/context exceeds the conservative GPU memory budget, Automatic chooses CPU. No cloud inference is used.
