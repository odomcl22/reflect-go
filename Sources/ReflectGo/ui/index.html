From drive to workstation
  1. Bring your models
    If needed, download or import a model in Model library. Models for your apps lets you offer all suitable models or a selected set, with an optional default for each client.
  2. Open your app
    Click Open Codex CLI, Open Claude CLI, or Open OpenCode CLI. Reflect Go starts the local service and supplies your saved models automatically. No model loads until it is requested.
  3. Choose a project only if you want to
    Leave the project blank to start in the portable Workspace, or choose an existing folder before opening your client. Clients retain their own tool approvals. Claude may ask to use Reflect Go’s supplied API key: choose Yes for this local connection.
  4. Finish and unplug
    Finish client tasks, stop the engine, and quit Reflect Go before ejecting. Closing a browser tab leaves its launcher running. Models and settings travel; project build tools and GPU drivers come from the host.
Supported platforms are qualified explicitly
Mac, Windows, and Linux builds need physical-device qualification. Chromebooks require a suitable Linux environment and drive permissions. The engine never silently falls back to cloud inference.
