From drive to workstation
  1. Prepare your models
    Download or import a model in Model library. Use Recommend settings for this computer. Enable models and choose a default.
  2. Start the engine
    The engine exposes enabled models. It loads one when a client requests it. A second simultaneous request receives a busy message; finish or cancel the current response before retrying.
  3. Open a client
    No project selection is required here. The default Workspace lives beside the phases on your drive. Use Open with a project for an existing folder. Clients retain their own tool approvals. Claude may ask to use Reflect Go’s supplied API key: choose Yes for this local connection.
  4. Finish and unplug
    Finish client tasks, stop the engine, and quit Reflect Go before ejecting. Closing a browser tab leaves its launcher running. Models and settings travel; project build tools and GPU drivers come from the host.
Supported platforms are qualified explicitly
Mac, Windows, and Linux builds need physical-device qualification. Chromebooks require a suitable Linux environment and drive permissions. The engine never silently falls back to cloud inference.
